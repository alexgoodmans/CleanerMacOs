# Again Cleaner — портфолио

**Again Cleaner** — безопасная очистка диска для macOS 26.5+. Бесплатно, без подписки, Developer ID + notarize. Сайт: [againcleaner.com](https://againcleaner.com).

## Для бизнеса / позиционирование

Это **утилита доверия**, не «ещё один CleanMyMac». Ценность — прозрачность: категории с тегами Safe / Caution / Risky, рискованные пункты никогда не предвыбраны, удаление по умолчанию в Корзину. Опасные места (Keychain, Mail, Messages, iCloud Documents) в каталоге просто отсутствуют.

Монетизация сейчас — донат. Продукт работает как витрина качества MediaRise на нативном macOS.

## Что умеет

- Каталог кэшей приложений, Electron/Chromium junk, артефакты сборки (`node_modules`, `target`, `.venv`, Gradle, vendor…) только при наличии маркер-файлов проекта.
- Smart Scan с модульными сканерами и Deep Disk (дерево размеров).
- Крупные файлы по порогу, избранные папки «почистить одним кликом».
- Локализация: English, Русский, ไทย.
